# DSA-LAB-06

CS-250 Data Structures and Algorithms - Lab 6 (Stacks and Queues), written in C++.

| File | Task |
|------|------|
| `Task1.cpp` | Expression conversion and evaluation (infix, prefix, postfix) using stacks |
| `Task2.cpp` | Expression validators using a stack: bracket checker and HTML/XML tag checker |
| `Task3.cpp` | Print server request handling system using a circular queue |
| `Task4.cpp` | Waiting room management system using a queue |

## Build and run

```bash
g++ Task1.cpp -o task1
./task1
```

Replace `1` with `2`, `3` or `4` for the other tasks.
